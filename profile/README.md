## `// como trabalhamos`

```
diagnóstico ──► arquitetura ──► automação ──► escala
```

1. **Diagnóstico** — mapeamos a operação e os gargalos onde a automação gera mais retorno.
2. **Arquitetura** — desenhamos fluxos, agentes, integrações, dados e segurança antes de escrever código.
3. **Automação** — implantamos em ciclos, testando com dados reais.
4. **Escala** — monitoramos, otimizamos e expandimos junto com o negócio.

## `// nossos compromissos`

- **Estrutura antes de código** — menos surpresa, menos retrabalho.
- **Aproveitamos o que você já tem** — trocar ferramenta só quando ela impede o resultado.
- **Entrega testada, não prometida** — cada automação entra em operação validada.
- **Suporte depois da entrega** — monitoramento, ajustes e evolução contínua.

## `// segurança & LGPD`

Privacidade e segurança entram no projeto desde o primeiro desenho: mapeamento de dados pessoais e
bases legais, isolamento de dados por cliente, humano no controle de ações sensíveis de agentes,
trilha de auditoria e provedores de IA que não treinam com os dados dos clientes.
